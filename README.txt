## 📋 Project Description

The research team at my organization needed to update the file
permissions for certain files and directories within the
`projects` directory.

The existing permissions did not reflect the appropriate level
of authorization. Checking and updating these permissions helps
keep the organization's system secure.

### 🛠️ Tools Used

| Tool | Purpose |
|:---:|---|
| `ls -la` | View files, directories, hidden files, and permissions |
| `chmod` | Modify file and directory permissions |
| Linux Terminal | Execute and verify commands |
